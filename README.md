## 03 / The source

A lightweight static website built with **HTML, CSS, and JavaScript**, published through **GitHub Pages**. No package installation or build step is required.

| File | Purpose |
| :--- | :--- |
| [index.html](index.html) | Page structure, metadata, navigation, and bilingual text |
| [style.css](style.css) | Visual identity, responsive layouts, themes, and motion |
| [refresh-2026.css](refresh-2026.css) | Editorial refresh, improved portrait framing, new case sections and mobile refinements |
| [app.js](app.js) | Project data, language/theme controls, filters, and interactions |
| [portrait.jpg](portrait.jpg) | Portfolio portrait |
| [favicon.svg](favicon.svg) | Personal monogram |
| [resume-en.pdf](resume-en.pdf) · [resume-fa.pdf](resume-fa.pdf) | Downloadable résumés |

### Preview locally

With Python 3 installed, run this command from the repository directory:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`. Edit shared page content in `index.html`, project and career data in `app.js`, and styling in `style.css`.
